# EduZone Learn — MOE source shelf integration (8 November 2026)

## Getting started

1. Publish the **entire ZIP contents** to the root of a GitHub Pages repository (do not upload only index.html).
2. Open `index.html` and use the top buttons to switch National, British, American; language is English, formal Arabic or Egyptian conversational Arabic.
3. Under **National**, choose a grade from 15 available groups (KG1 through Secondary 3 and Baccalaureate 2 as a separate category). Choose **Textbook sources** to open that grade's first-term source listing. Or use the `moe-books.html` source shelf to browse all grade categories.
4. For **National Primary 4 Math**, the original 51 guided lessons remain available. For **National Preparatory 3 Science**, the ten developed interactive lessons remain available. Other subjects/grades may have only book source listings and have no completed EduZone interactive learning course yet.
5. The **British Year 4** reference map with 35 skills, Math Studio games and Science enrichment remains separate. The **American** selection remains a partial reference pathway; MOE National books are never silently assigned to British/American.

## What is actually included

- 15 National grade/pathway source records, **286 first-term edition listings counted** (some are variants by language). Each record contains an external directory page linking to MOE-hosted PDFs. The 286 individual PDF files are **not bundled** and are **not fully analysed**.
- Two previously located direct MOE-hosted PDF links (Primary 4 Math English and Preparatory 3 Science English). They are web references, not files stored here; external links can change.
- Original EduZone 51 Grade 4 Math lesson files, British Year 4 skill map + eight interactive Math Studio activities, Prep 3 Science ten lesson models, Grade 4 Science topic, STEM labs.
- All prior student voice settings: formal + story/example browser narration; **not** guaranteed professional female voices.

## Source transparency

- MOE student library: https://studentbooks.moe.gov.eg/Books
- MOE electronic library: https://ellibrary.moe.gov.eg/books/
- Grade-by-grade directory: https://miskeg.app/books/
- Dataset: `moe/grade-index.json`, `moe/direct-links.json`, `moe/source-index.csv`
- Scope: **Term 1, 2026–2027**. Term 2 not claimed. National sources are not formal curriculum-alignment evidence for British/American.
- The website does **not** redistribute complete Ministry textbook PDFs or assert that all textbook content has been turned into games. Each source must be individually read and verified before building precise unit/lesson mappings.

## Technical status

JavaScript syntax and local file integrity were validated. Full browser interaction verification was unavailable due to local browser navigation being blocked. Run the site from HTTPS/GitHub Pages; browser speech recognition and synthesis vary across devices.
