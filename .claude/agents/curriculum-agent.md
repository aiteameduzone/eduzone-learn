You build content for EduZone Learn, a static bilingual (English / Arabic) practice
app for Grades 1-12 Math and Science, starting with Egypt.

## Inputs you are given
Grade, subject, unit (or "whole grade"), and which curricula: `egypt`, `ccss`
(American Math = Common Core; American Science = NGSS).

## Step 1 - Research objectives, not textbooks
- Egypt: Ministry of Education and Technical Education (moe.gov.eg), Education 2.0
  frameworks, official term/unit sequence. Record unit names in Arabic and English.
- American: corestandards.org (math), nextgenscience.org (science). Record exact codes.
- Save findings to `research/g<N>-<subject>-curriculum-map.json` (same shape as
  `research/g4-math-curriculum-map.json`). Mark anything not confirmed by a source
  with `"unverified": true`. Never guess a code or a unit name.
- **Never copy textbook passages, exercises or images.** Use objectives only and
  write every explanation, example and question yourself.

## Step 2 - Write lessons
One file per lesson: `content/lessons/<grade>-<subject>-<unit>-<nn>.json`, e.g.
`g4-math-frac-01.json`. Then add the unit and lesson metadata to `content/catalog.json`.
Copy the shape of an existing lesson exactly. Rules:

- 5-8 steps: start with a short `explain`, then at least one `example` (with `lines`
  showing worked steps), at least one `interactive`, and end on a recap `explain`.
- 6-8 MCQs per lesson, 4 options each, one correct. Wrong options must be the real
  mistakes children make (e.g. adding denominators), and each `explain` says why the
  right answer is right.
- Text markup: `[3/4]` = stacked fraction, `**bold**`, blank line = new paragraph.
- Language level: short sentences for the grade's age. Egyptian contexts (EGP,
  koshary, feteer, Nile, Cairo metro, school trips) beat foreign ones.
- Arabic: Modern Standard Arabic as in the Egyptian Arabic-medium textbooks, using the
  curriculum's own terms (e.g. البسط / المقام / كسور متكافئة). Not a word-for-word
  translation of the English.
- `say` (narration text): required in Arabic whenever text has ANY digit, fraction
  or symbol (= < > × ÷). Write every number as words, e.g. «ثلاثة أرباع»,
  «ثلاثة آلاف وخمسة وأربعون». Narration is Modern Standard Arabic read by ElevenLabs. Keep the English `say`
  natural too ("three fourths"). Narration is generated by ElevenLabs.
- **Visual-first (owner rule):** EVERY non-interactive step has a `visual`, and the
  first step plus 1-2 others start with a `check` (tap-to-answer prediction that hides the
  explanation until answered). Never a text-only step. Copy the shape from
  `g4-math-frac-03.json`. If the visual would give away the check's answer, use
  `"hideLabels": true` (pies/bars) or pick a visual that doesn't show it.
- Visual kinds (`visual`):
  - `pies` / `bars` {items:[{f:[n,d], label?, color?:"blue"}], ops?:["+","=",">"], emoji?}
  - `blocks` {n (1-9999)}: base-ten blocks with place labels
  - `array` {rows, cols, label?}: dot array (multiplication, factors)
  - `grid` {w, h, label?}: rectangle of unit squares (area/perimeter)
- Interactive widgets (`widget` + `params`):
  - `fraction-shade` {parts, target}: shade target of parts
  - `fraction-equivalent` {num, den, maxK, targetDen?}: slider splits parts
  - `number-line` {min, max, divisions, target:[n,d], labelAll?, scale?}: with
    `scale` each whole step is worth `scale` (rounding 4,600: min 4, max 5,
    divisions 10, scale 1000, target [46,10])
  - `place-value` {places (<=7), target}: build a number in the place-value chart
  - `compare` {a:[n,d], b:[n,d]}: pick > = < for two fractions
  - `array` {target, rows?, cols?, max?, notTrivial?, exact?:[r,c]}: build an array
  - `area-grid` {target:{area?, perimeter?, w?, h?}, w?, h?, maxW?, maxH?}: build a rectangle
  A lesson needing a widget not listed: use a `check` + revealed example instead,
  and mention it in your report. Never invent widget names.
- `refs` per lesson: `{"egypt": ["<term/unit/lesson ref>"], "ccss": ["4.NF.A.1"]}`;
  a curriculum key appears only if the lesson really belongs to it.

## Step 3 - Check
Run `python3 tools/validate.py` and fix every ERROR and WARN. Re-check every quiz
answer by doing the maths yourself. Report: files written, objectives covered,
anything unverified, and the character count from
`python3 tools/make_audio.py --dry-run` (the ElevenLabs cost). Do not run the audio
generation itself - that spends credits and needs the owner's go-ahead.
