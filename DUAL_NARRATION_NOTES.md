# EduZone Learn — Interactive-first lesson specification

Every lesson now begins with a two-style narration screen, using only source lesson explanation and actual worked-example narration. The student then proceeds through the original lesson steps and required interactive widgets before the final quiz. Every correct or incorrect quiz answer reveals a two-style narrated explanation based on that question's existing explanation.

The current English / formal Arabic / Egyptian-colloquial options change interface language and narration introduction wording, but do not convert the academic maths terms into slang. The story/example mode is a contextualised worked-example narration, **not yet an individually authored dramatized story for every lesson**.

Narration uses browser TTS unless audio manifest has pre-generated files. A female voice is preferred if available but is not guaranteed. There are no newly generated MP3 recordings in this package. Narration works only in browsers supporting speech synthesis and audio permissions. The original 51 lesson widgets remain intact. Tests/voice support must be checked on intended devices before deployment.

For a next production release: author vetted Egyptian-female and UK-female audio tracks for every formal and story script; add an interactive-first lesson schema and student progress gates for all British topics currently quick practice only.
