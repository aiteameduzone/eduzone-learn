# EduZone Learn — Student navigation update

Start at `index.html`. The new route is **Grade → Subject → Topic → Learning activities**. The header has separate **Curriculum** (British/National/American) and **Language** (English/Arabic/Egyptian conversational Arabic) switches. All existing original lesson, British map, Math Studio, Science and virtual-lab files remain in place. The logo file is included unchanged.

## What is currently available

- Grade 4 / British / Mathematics: 35 mapped skills, linked games and related full lessons or short quick practice. The British map is based on one school's reference plan, not a universal syllabus.
- Grade 4 / National or American / Mathematics: 51 original Grade 4 Math lessons across 9 populated units from the shared legacy content library, with cross-curriculum reference mappings (not a fully verified official course for either pathway).
- Grade 4 / Science: one topic (Adaptation for Survival). No claim of a complete syllabus match.
- Grade 4 / STEM: four optional enrichment lab simulations.
- Grade 5 / British / Mathematics: topic outline grounded in the uploaded Year 5 reference plan; playable activities are not yet available. Other Year 5 combinations are visibly marked unavailable.

## Deployment

Extract the ZIP and upload its contents to the root of a GitHub Pages repository (including subfolders). Choose *Settings > Pages > Deploy from a branch* / main / root. The content JSON is fetched at runtime, so a server / GitHub Pages is required; double-clicking HTML via `file://` may not load it.

No backend or guaranteed female voice recording is included. Existing Math Studio browser speech still depends on the device voice library.
